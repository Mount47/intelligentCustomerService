# 工具与业务技能

## 工具系统

工具是智能体访问订单、物流、退款、工单和政策服务的受控入口。当前工具数量和分类以
[项目状态](项目状态.md) 为准。

每个工具包含：

- 工具名称；
- 给模型看的用途说明；
- 输入结构；
- 实际执行函数；
- 统一结果格式。

所有执行结果统一表示为：

```text
是否成功
数据
错误代码和错误信息
```

失败通常作为工具结果返回模型，而不是直接让整个智能体崩溃。

## 最小权限

工具注册表包含系统全部工具，但每个技能只把完成当前任务所需的少量工具暴露给模型：

- 退款技能只开放退款核对相关只读工具；
- 物流技能只开放物流查询工具；
- 订单技能只开放订单、商品和物流查询；
- 通用技能只开放政策检索；
- 确认和取消等确定性流程可以不开放工具。

## 参数绑定

模型生成的用户编号和订单编号不可信。运行时会根据工具输入结构，以会话中的真实用户和订单
覆盖模型参数。服务层仍会再次检查订单归属，形成两道防线。

## 工具审计

每次工具调用保存：

- 会话编号；
- 工具名称；
- 脱敏后的输入和输出；
- 是否成功；
- 执行耗时；
- 错误信息。

## 四类业务技能

### 订单查询

指定订单时查询订单详情、商品和物流；未指定订单时由确定性代码列出本人近期订单。

### 物流处理

查询物流状态，检测长时间未更新或异常。正常情况直接回复，异常创建催件工单，签收未收到转人工。

### 退款处理

区分退款咨询、退款申请、退货申请、确认和取消。低风险申请先等待用户确认，高风险直接创建
待人工审核的退款申请并转人工。

### 通用处理

处理政策咨询和兜底情况；投诉与明确要求人工进入人工队列；超范围和低置信请求会在进入技能前
由核心管道短路。
