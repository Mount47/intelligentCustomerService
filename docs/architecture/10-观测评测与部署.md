# 观测、评测与部署

## 可观测能力

### 链路编号

接口收到请求后建立链路编号，并传入消息队列和工作进程。日志可以按同一编号串起一次处理。

### 工具审计

每次工具调用记录脱敏输入、结果、成功状态和耗时。

### 会话指标

智能体会话保存模型、令牌、估算成本、处理耗时、重试次数和错误原因。

### 运行指标

系统提供：

- 队列深度；
- 会话和工单状态分布；
- 自动解决与转人工情况；
- 服务时限；
- 质量统计；
- 模型成本；
- 服务监控指标。

## 两类质量检查

### 确定性会话质检

业务任务完成后异步生成质量记录，检查流程结果、工具成功率、禁语合规和人工升级事实。
它不评价复杂语义质量。

### 离线评测

模拟模型评测用于持续集成，验证意图、路由、工具、状态、转人工和合规规则。真实模型评测单独运行，
可以增加模型裁判，但必须记录模型、时间、成本和样例，不能把模拟得分当成真实模型能力。

## 前端

- 登录页获取短期访问凭证；
- 用户端发送消息、接收进度、查看回复和工具摘要；
- 管理端查看工单、会话、服务时限、质量和成本，并处理人工工单；
- 真实接口失败时明确显示错误，不使用模拟数据伪装成功。

## 部署方式

### 本地轻量模式

使用 SQLite、模拟模型和后台线程，适合快速理解主链路。

### 完整环境

使用：

- FastAPI 接口服务；
- Vue 前端；
- PostgreSQL；
- Redis；
- Celery 工作进程。

## 验证分层

| 验证方式 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 单元测试 | 函数和边界分支正确 | 真实基础设施协同 |
| 模拟模型评测 | 流程回归可重复 | 真实语义泛化 |
| PostgreSQL 并发测试 | 唯一约束和并发写入 | 线上整体容量 |
| Redis/Celery 联调 | 队列、重投和跨进程链路 | 大规模流量表现 |
| 接入层压力测试 | 落库和入队吞吐 | 真实模型推理吞吐 |
| 真实模型评测 | 指定模型在样例集上的效果 | 所有真实用户场景 |
